Design system · 1.0.0

Red, with the contrast to prove it.

Crimson UI is a dependency-free stylesheet. Primary, secondary, accent, and state colors all stay in the red family, and every text pair clears WCAG AA.

Usage

One file, no build

The built stylesheet is dist/crimson-ui.css. Source partials live in src/ if you want to import a slice.

<link rel="stylesheet" href="dist/crimson-ui.css">

<button class="btn btn-primary">Save swatch</button>

<style>
  :root {
    --color-primary: #7f1d1d;
    --color-primary-hover: #64141f;
  }
</style>
